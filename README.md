# Digital Red

Статическая реконструкция сайта `digital-red.ru`, подготовленная для независимого хранения и размещения вне Tilda.

## Структура

- HTML-страницы и локальные исправления сайта размещены в корне репозитория.
- `static.tildacdn.com/`, `neo.tildacdn.com/`, `fonts.googleapis.com/` — локальные копии ресурсов, используемых страницами.
- `.github/workflows/pages.yml` — публикация статического предпросмотра через GitHub Pages.

## Локальный запуск

```bash
python3 -m http.server 8080
```

После запуска откройте `http://127.0.0.1:8080/`.

## Формы и почта

GitHub Pages обслуживает только статические файлы. Формы отправляют заявки в отдельный API на сервере Digital Red. Доменная почта также работает отдельно от GitHub Pages.

Продакшен-секреты, базы данных, журналы и пользовательские данные в репозиторий не включены.
